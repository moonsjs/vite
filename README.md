# @moonsjs/vite

Plugin Vite + runtime server untuk framework [**Moons**](https://github.com/moonsjs/docs):
transform zero-trust `*.server.ts` (§12), virtual module, dev SSR, build client+server,
graceful shutdown, dan health endpoint.

- Dokumentasi API: [docs/api/vite.md](https://github.com/moonsjs/docs/blob/main/docs/api/vite.md)
- Kenapa zero-trust: [docs/manifest.md](https://github.com/moonsjs/docs/blob/main/docs/manifest.md)
